## 🚀 Kurulum ve Kullanım

Bu notları kendi bilgisayarınızda çalıştırmak ve incelemek için aşağıdaki adımları izleyebilirsiniz:

1.  **Repoyu Klonlayın:**

    ```bash
    git clone https://github.com/Emir-Kanbur/python-learn.git
    cd python-learn
    ```

2.  **Sanal Ortam Oluşturun (Opsiyonel ama önerilir):**

    ```bash
    python3 -m venv venv
    source venv/bin/activate  # Mac/Linux
    # venv\Scripts\activate   # Windows
    ```

3.  **Jupyter Notebook'u Başlatın:**
    ```bash
    pip install notebook
    jupyter notebook
    ```
