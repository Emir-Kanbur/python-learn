# Python Öğrenme Serüveni 🐍

Bu repository, Python programlama dilini öğrenirken aldığım notları, çözdüğüm egzersizleri ve Jupyter Notebook çalışmalarımı barındırmaktadır.

## 📂 İçerik

Proje içerisinde farklı kaynaklardan takip ettiğim derslerin notları yer almaktadır:

- **python-udemy/**: Udemy üzerinden takip ettiğim Python kursuna ait ders notları ve örnek kodlar.
- **Python Dersleri - Furkan.Ozturk/**: Furkan Öztürk'ün kaynaklarından yararlanarak oluşturduğum notlar ve uygulamalar.

## 🚀 Kurulum ve Kullanım

Bu notları görüntülemek ve çalıştırmak için bilgisayarınızda Python ve Jupyter Notebook kurulu olmalıdır.

1. Repoyu klonlayın:

   ```bash
   git clone https://github.com/KULLANICI_ADINIZ/python-learn.git
   ```

2. Klasöre gidin:

   ```bash
   cd python-learn
   ```

3. Jupyter Notebook'u başlatın:
   ```bash
   jupyter notebook
   ```

## 🛠 Kullanılan Teknolojiler

- Python 3
- Jupyter Notebook
