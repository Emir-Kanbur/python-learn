# Python Learn

Bu depo, Python öğrenme sürecimde tuttuğum Jupyter Notebook notlarını ve alıştırmaları içerir.

## İçerik

- `python-udemy/Jupyter-Notebook/`
  - Temel Python konuları: sayılar, string, list, dictionary, set, tuple, koşullar ve döngüler.
- `Python Dersleri - Furkan.Ozturk/`
  - Kapsamlı tutorial notebook serisi.

## Gereksinimler

- Python 3.10+
- `pip`
- Jupyter Notebook veya JupyterLab

## Kurulum

```bash
git clone https://github.com/Emir-Kanbur/python-learn.git
cd python-learn
python3 -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Kullanım

```bash
jupyter notebook
```

Ardından notebook dosyalarını açarak sırayla çalışabilirsiniz.
