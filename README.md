# Python Öğrenme Notları

Bu depo, Python öğrenme sürecimde hazırladığım Jupyter Notebook notlarını ve alıştırmaları içerir. İçerik hem Türkçe hem İngilizcedir.

## İçerik

- [`python-udemy/Jupyter-Notebook/`](python-udemy/Jupyter-Notebook/): Atıl Samancıoğlu'nun Python 100 Günlük Yazılım Kampı'nı takip ederken oluşturduğum kişisel notlar ve örnekler. Bunlar Udemy'nin resmi kurs materyalleri değildir.
- [`Python Dersleri - Furkan.Ozturk/`](Python%20Dersleri%20-%20Furkan.Ozturk/): Temel Python, NumPy, Matplotlib ve SciPy konularında tutorial notebook'ları.

## Kaynaklar ve atıflar

- `Python_Tutorial_1.ipynb`, `Python_Tutorial_2.ipynb` ve `Python_Tutorial_3.ipynb`, [CS231n Python v3.0 tutorial'ından](https://github.com/cs231n/cs231n.github.io/blob/master/python-numpy-tutorial.md) türetilmiştir. Kaynakta Justin Johnson atıfı yer alır. CS231n deposundaki MIT lisans metni ve telif bildirimi [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) dosyasında bulunur.
- [Furkan Öztürk - Python Dersleri](https://scholar.harvard.edu/furkanozturk/python-dersleri) ve [Python Dersleri video listesi](https://youtube.com/playlist?list=PLG3W_TrKSZT9NBMizl3oO2pC7UoPC-nP8) ek öğrenme kaynaklarıdır.
- [Atıl Samancıoğlu - Python 100 Günlük Yazılım Kampı](https://www.udemy.com/course/python-100-gunluk-yazilim-kampi/) `python-udemy` notları için yararlanılan kurstur. Bu depo Udemy veya eğitmen tarafından hazırlanmış resmi bir kurs deposu değildir.

## Gereksinimler

- Python 3.10+
- `pip`
- Jupyter Notebook veya JupyterLab

## Kurulum

```bash
git clone https://github.com/Emir-Kanbur/python-learn.git
cd python-learn
python3 -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Kullanım

```bash
jupyter notebook
```

Ardından notebook dosyalarını açarak çalışabilirsiniz.
