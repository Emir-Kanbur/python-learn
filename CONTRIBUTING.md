# Contributing

Katkıda bulunmak isterseniz aşağıdaki adımları izleyin:

1. Bu repoyu fork edin.
2. Yeni bir branch oluşturun: `git checkout -b feat/degisiklik-adi`
3. Değişikliklerinizi yapın.
4. Commit atın: `git commit -m "feat: kısa açıklama"`
5. Branch'i gönderin: `git push origin feat/degisiklik-adi`
6. Pull Request açın.

## Notlar

- Notebook dosyalarında değişiklik yaparken açıklayıcı hücre notları eklemeye özen gösterin.
- Mümkünse örnekleri çalıştırıp hatasız olduğundan emin olun.
